# Mathiyazhagan S - Developer Portfolio

A modern, high-performance developer portfolio website designed for **Mathiyazhagan S** (B.E. Computer Science Graduate, Full Stack Developer & Software Engineer). Actively looking for full-time opportunities with immediate availability.

## 🚀 Features

- **Responsive Modern UI**: Dark-mode primary cyber/deep slate design with glassmorphism and smooth micro-interactions.
- **Interactive Background**: Animated constellation particle canvas responding to mouse movements.
- **Dynamic Typewriter**: Hero section with interactive role cycling.
- **Live Skill Search**: Real-time filtering and highlighting across 6 technical categories.
- **Interactive Project Showcase**:
  - 12 Public Repositories imported directly from GitHub (`MATHIYAZHAGN21`).
  - Filter by project type (*All Repositories, Full Stack & MERN, React & Modern Web, Productivity & Tools*).
  - Direct links to every GitHub repository and case study deep-dive modals.
- **ATS Printable Resume Modal**:
  - Complete, verbatim reproduction of Mathiyazhagan's resume.
  - One-click **"Print / Save as PDF"** button with dedicated `@media print` styling for recruiters.
- **Interactive Contact Section**:
  - Direct 1-click clipboard copy for email and phone with toast feedback.
  - Functional contact message form with `mailto:` email generation.
- **Dark / Light Mode**: Seamless theme toggle with state persisted in `localStorage`.
- **Zero Build Dependencies**: Pure HTML5, CSS3, and modern Vanilla JavaScript. Works instantly offline or online.

## 🌐 Deploy to GitHub Pages (Free)

1. Create a repository on GitHub named `portfolio` or `MATHIYAZHAGN21.github.io`.
2. Push the files in this directory to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   git branch -M main
   git remote add origin https://github.com/MATHIYAZHAGN21/<repo-name>.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** > **Pages** > Select `main` branch and root `/` > Click **Save**.
4. Your portfolio will be live at `https://MATHIYAZHAGN21.github.io/<repo-name>/`!
